# Notebooks

## Grid Search Analysis

Use `notebooks/hparams_grid_search_analysis.ipynb` to analyze and compare grid search runs from W&B or local CSV outputs.

### Quick start

1. Ensure dependencies are installed (see `requirements_dev.txt` and `pyproject.toml`).
2. Set `WANDB_API_KEY` if you want to pull runs from W&B.
3. Open the notebook and run cells top-to-bottom.

The notebook exports summary tables to `notebooks/analysis_outputs/`.
